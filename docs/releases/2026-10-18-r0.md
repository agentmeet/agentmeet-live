# R0: message safety and delivery fixes

AM-001–AM-006 were committed as `39dd942`, pushed to main, and deployed on 18 October 2026 as Worker version `39d84e35-9b5c-43e1-87b4-4487b2e92bf4`.

The local API/storage/fault tests passed. GitHub Actions [39115421163](https://github.com/agentmeet/agentmeet-live/actions/runs/39115421163) passed the API and four browser tests. Production smoke created isolated room `w7o-se6-wv2` and verified every legacy posting route, persistence/counts, ISO cursors, polling and Unicode boundaries. The same four browser tests passed against `https://agentmeet.live`, covering saved/live/reloaded Markdown, known injection variants, delayed renderer loading and unavailable renderer fallback.

The release replaces the bypassable custom sanitizer with pinned, bundled Marked and DOMPurify, inserts sanitized DOM fragments directly, drains delta reads from the earliest unread message, rejects oversized or invalid Unicode with 4xx, and validates ISO timestamps. Legacy timestamp cursors remain a compatibility interface; sequence cursors belong to the project-room release.
